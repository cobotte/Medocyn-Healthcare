# Security Policy

## Supported Versions

Only the latest version of Medocyn Healthcare Portal is actively supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take the security of our services seriously. If you find a security vulnerability, please report it via the contact page of the portal or by opening a private security advisory on GitHub.

Please do not open public issues for security vulnerabilities.
